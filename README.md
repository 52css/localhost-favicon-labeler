# Local Favicon Labeler

给本地、测试或其他环境的网站 favicon 添加醒目的文字标记，避免在多标签页中混淆环境。

## 安装

1. 打开 `chrome://extensions`（Edge 请打开 `edge://extensions`）。
2. 开启右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本文件夹。
4. 打开扩展详情页并点击「扩展程序选项」，按需要调整规则。

默认规则会匹配 `localhost`、`127.0.0.1` 与 `[::1]`，显示橙色 `LOC`。

扩展会在页面加载完成后读取现有 favicon，由后台脚本转为 data URL，再使用 SVG `foreignObject` 将原图与环境标签合成并替换同一个 favicon 链接。它不会重定向或替换页面的 favicon 请求，因此不会丢失 Next.js 或其他项目原有的图标；也不包含任何项目名称或端口的写死逻辑。

## 规则

- 每一行是一个规则，按从上到下的顺序匹配。
- `*` 匹配任意字符，例如 `dev*` 能匹配 `dev.example.com`。
- 多个域名可使用英文逗号或换行分隔。
- 保存后，当前已打开的匹配页面会自动重新标记；若页面自行频繁更新图标，刷新页面即可。
